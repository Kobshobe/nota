# Spec: 独立「我的」页

## Behavior

- 事项页 AppBar：标题「事项」+ 右侧人像图标按钮（tooltip「我的」），不再渲染额度徽标和退出登录。
- 点人像图标进入 `/profile`：「我的」页，左上角返回事项页。
- 「我的」页内容：头像占位（邮箱首字母）、邮箱、会员标签（`isVip` 为真显示 VIP，否则 Free）、今日额度（不限次或 `已用 / 上限`，注明每日 0 点重置）、退出登录。
- 退出登录沿用确认弹窗；确认后清空会话与本地通知，路由回到登录页。
- 额度加载失败时该项显示「额度加载失败」，不阻塞其他内容。

## Alternatives considered

- **保留额度徽标在事项页，只加一个头像入口**：用户明确说事项页不要 VIP 之类。
- **把账号信息做成底部导航第三个 tab**：只有三个页面，弹层/page 足够，导航栏已经在上一轮删掉。
- **退出登录仍留在事项页**：和账号信息放一起更自然。

## Areas of concern

- 退出登录依赖路由的 refreshListenable 跳转，深链接直接打开 `/profile` 时返回按钮走 `go('/')`。
- 会员状态只按邮箱是否含 vip 判断，和现有规则一致。
