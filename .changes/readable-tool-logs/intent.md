# Intent: 可读的工具调用日志

## Problem

Agent 每次运行会调用若干工具，但服务端只在失败时打日志，正常的一次运行在终端里看不到任何工具调用；客户端回看工具轨迹时把参数和结果原样 JSON 展示，中文和字段名混在一起，读不出「做了什么、结果是什么」。

## Outcome

- 服务端每次 Agent 运行都有日志：运行开始/结束、每个工具的开始与结束、耗时和失败原因。
- 日志一行一句中文，字段以 `key=value` 拼接，不打印 JSON。
- 服务端终端默认输出人类可读的日志行，需要机器解析时显式切回 JSON。
- 客户端工具轨迹弹窗按中文字段逐条展示参数和结果，不再出现 JSON 大括号。

## Constraints

- 不改变契约、Agent 工具语义、额度与鉴权。
- 日志不新增敏感信息：不打印 JWT、模型 key、完整历史消息。
- 日志失败不得影响 Agent 运行。
