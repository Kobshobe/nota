# Intent: 发出第一条内容才创建会议

## Problem

点主对话右上角的会议按钮会立刻建一条会议数据，用户还没输入就多出一场空会议；空会议还会作为「最近会议」卡片堆在对话上方，看起来像一串「新会议」。

## Outcome

- 会议按钮只打开一张空白会议页，不写任何数据。
- 用户在里面发出第一条内容时才创建会议，并进入这场会议。
- 主对话里不再有「最近会议」横条；已创建的会议作为卡片出现在对话时间线里，点卡片进入会议。

## Constraints

- 不新增接口：仍然是 `POST /threads` + `POST /threads/{id}/messages`。
- 不引入会议删除/归档；创建后中途放弃的极端情况保留空会议。
