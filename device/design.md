# Nota 会议录音设备

设备是一支只录音、不回放的会议录音笔：进入会议室按一下按钮开始录音，会议结束再按一下结束，录音上传后由服务端转写成会议纪要，出现在 App 的主对话时间线。设备没有屏幕和扬声器，按钮和指示灯就是全部交互。

## 形态

模拟器由 Wokwi 提供：ESP32 DevKitC V4，按钮接 GPIO4（内部上拉，按下为低），指示灯接 GPIO5，USB 供电。真机在同一形态上增加麦克风和 microSD，用来采集和存放整场录音；8 分钟的压缩音频约 2 MB，SD 卡容量不是瓶颈。模拟器没有麦克风，输入是固件内嵌的固定会议音频；也没有扬声器，设备不播放任何声音。

## 状态机

| 状态 | 指示灯 | 行为 |
|---|---|---|
| 待机（无待发录音） | 灭 | 按下开始录音 |
| 待机（有未发送录音） | 灭 | 按下重试；长按 2 秒丢弃 |
| 录音中 | 常亮 | 再按或满 8 分钟进入上传 |
| 上传中 | 慢闪 | 上传并轮询，直到成功或失败 |
| 失败 | 快闪 10 秒 | 回到待机并保留录音 |

- 慢闪为 1 Hz（亮 500 ms / 灭 500 ms），快闪为 5 Hz（亮 100 ms / 灭 100 ms）。
- 录音满 480 秒自动结束并上传；设备没有屏幕，不提前提示。
- 上传拿到 202 后每隔 5 秒查询一次，最长 5 分钟；查询到 completed 熄灭，failed 或超时进入失败。
- 上传中再按按钮不打断上传，设备忽略这次按键。
- 轮询超时的重试先查同一个录音 id，可能仍在后台完成；从未拿到 id 的上传失败才重新上传。
- 服务端明确 failed 的重试重新上传新录音；失败已退额度，不会重复扣。
- 长按 2 秒只在待机且有未发送录音时生效，丢弃本地文件并回到无待发录音的待机。

## 录音与上传

- 录音以压缩格式落 microSD；模拟器不落盘，直接用内嵌 fixture 代替。
- 结束时整段上传 `POST /api/device/recordings`：multipart，`audio` 必填，`durationMs` 可选，服务端返回 202 和录音 id。
- 单场硬上限 480 秒 / 12 MB，与 App 会议录音一致；超限由服务端拒绝，设备按失败处理。
- 上传失败、服务端 failed、轮询超时都进入失败状态；成功后删除本地录音。
- 设备不下载任何音频，服务端也不为设备合成语音。

## 身份与归属

- `npm --prefix server run seed:device` 创建演示用户与一台设备；token 明文只打印一次，数据库只存 SHA-256。
- 设备请求带 `Authorization: Bearer <device-token>`；只能读写自己创建的录音，跨设备访问返回 404。
- 设备预绑定一个用户；会议出现在该用户的主对话时间线，一场会议扣 1 次额度，失败不扣、重试不重复扣。

## 服务端

- 复用 App 的会议管线：转写 → 转写成功后才创建会议 thread → 转写全文作为第一条消息 → Agent 生成 title、summary、keyPoints 和候选待办 → 主对话时间线卡片。
- 原始音频在转写成功后删除；失败保留 24 小时。
- 设备只上传和查询状态，不参与纪要生成，也读不到纪要内容。

## 协议

- 上传：`POST /api/device/recordings`，返回 202 和 `Recording`。
- 状态：`GET /api/device/recordings/{recordingId}`，`completed` 时带 `threadId`。
- 字段、错误码和状态码以[契约](../contract/openapi.yaml)为准；设备认证使用 `deviceAuth`。

## 模拟器映射

- Wokwi 免费网页版；工程内容在 [`firmware/diagram.json`](firmware/diagram.json) 和 [`firmware/nota_device.ino`](firmware/nota_device.ino)。
- 串口先打印 `paste: <baseUrl> <token>`，粘一行后连接；之后按按钮或用串口 `s` 开始/结束，`d` 等同长按 2 秒放弃。
- 内嵌约 40 秒的双人会议对话作为 fixture；按下开始只切换到录音态并计时，结束才上传这段音频，所以 8 分钟上限在模拟器里不会触发。
- 灯效、上传、轮询、失败重试都真实运行；转写和纪要走真实服务端。
- HTTPS 用 `setInsecure()`，只用于本地隧道；token 只从串口注入，不写进固件；免费项目公开且走公共网关，token 和音频会经过 Wokwi，不放真实敏感内容。

## 限制与非目标

- 不做超过 8 分钟的会议和切片转写；长会议另开变更。
- 不做设备音频输出、TTS、实时上屏。
- 不做配网、手机绑定、BLE；设备由 seed 预置。
- 不涉及真机结构、电源与出货；microSD 是固件假设，模拟器不验证存储。
- 断电不保证恢复：录音中断电可能丢失整场。
