# Grill to the bottom

Interrogate the user about one matter until both sides share a clear picture. Walk every branch of the decision tree, resolving one dependency at a time. Give your recommended answer for each question.

Ask one question at a time and wait for the answer before continuing. Throwing several questions at once overwhelms people.

If a fact can be looked up by exploring the environment (filesystem, tools), look it up instead of asking the user. But decisions belong to the user — every decision goes to the user to make, and you wait for their answer.

Don't start executing until the user confirms you share the same picture.
